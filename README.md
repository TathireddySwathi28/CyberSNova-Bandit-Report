## About the project

[OverTheWire Bandit](https://overthewire.org/wargames/bandit/) is a free, legal
"wargame" that teaches the basics of Linux, the command line, and security
concepts through a series of levels. Each level is a small puzzle; solving it
reveals the password needed to log into the next level.

This repository contains my report documenting **Levels 0 to 20**. For every
level it records the objective, the exact commands used, the reasoning behind
the solution, the password obtained, and a screenshot of the output as proof.

## Skills practised

Linux command-line navigation, SSH & SCP, file searching (`find`, `grep`),
text processing (`sort`, `uniq`, `strings`, `tr`), encoding/decoding (Base64,
ROT13), handling repeatedly-compressed files, SSH key authentication, raw and
encrypted network connections (`netcat`, `openssl`), port scanning with `nmap`,
and privilege concepts such as setuid binaries.
